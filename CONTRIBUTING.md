# Contributing

This repository publishes shared AVALSYS client primitives for review and reuse
inside the AVALSYS product family. External contributions are not currently
accepted unless maintainers request them explicitly.

Keep proposed primitives product-neutral. Do not add product ownership,
billing, credit, provider, or private deployment behavior to shared packages.

Report vulnerabilities through the private process in
[`SECURITY.md`](./SECURITY.md).
